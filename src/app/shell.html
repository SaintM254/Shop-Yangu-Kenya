Import your records

Before you start

Three things make an import go through cleanly
  1. Use the template for the sheet you are importing — the column names must match.
  2. Write dates as DD/MM/YY (01/04/26) — the same as every receipt and report. Anything else is reported, not guessed.
  3. Leave a product's SKU or a sale's receipt_no blank and the app makes one — you never have to invent codes.
  4. Import the oldest records first: stock, then customers, then sales.
