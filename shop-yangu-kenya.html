Before you start

Three things make an import go through cleanly
  1. Use the template for the sheet you are importing — the column names must match.
  2. Write dates as YYYY-MM-DD (2026-04-01). Anything else is reported, not guessed.
  3. Import the oldest records first: stock, then customers, then sales.
